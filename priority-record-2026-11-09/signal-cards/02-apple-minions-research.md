# Signal card 02 — Apple "Minions": research, not a commercial product

- Event date: 9 Oct 2026 (arXiv v1); listed by Apple Machine Learning Research, October 2026
- Sources: [Apple Machine Learning Research](https://pr-mlr-shield-prod.apple.com/research/distributed-gpu-cloud) · [arXiv:2610.12970](https://arxiv.org/abs/2610.12970)
- What it is: "Minions: A Dynamic and Distributed Virtual GPU Cloud Built on Idle Apple Silicon Devices". The authors report that "idle macOS devices can be transformed into a practical distributed GPU inference platform".
- Overlap with the 2025 proposal: idle personal hardware pooled into a distributed inference resource.
- Difference: a research system and the authors' experience with it. The sources do not describe a commercial product, an external marketplace or owner payouts.
- What transfers: evidence that pooling idle personal devices for inference is technically workable, which supports a permissioned internal pilot before any marketplace.
- Proposal date for comparison: 11 Oct 2025 (GitHub release v12.10.2025).
